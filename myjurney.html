Starting the Journey

Perjalanan saya dimulai ketika saya menjadi mahasiswa Program Studi Pendidikan Sistem dan Teknologi Informasi. Di awal perkuliahan, saya mulai mengenal lebih banyak tentang dunia teknologi, belajar hal-hal baru, dan mendapatkan pengalaman berinteraksi serta bekerja sama dengan teman-teman.

Exploring & Learning

Selama dua semester pertama, saya mulai mencoba berbagai hal melalui tugas dan proyek perkuliahan. Dari beberapa proyek tersebut, saya belajar mengenal teknologi yang berbeda, mencoba membuat sesuatu secara langsung, dan memahami bagaimana proses pengembangan sebuah proyek dilakukan.

Still Exploring
